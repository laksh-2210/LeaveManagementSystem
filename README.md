# Leave Management System

A Full Stack Leave Management System that helps users apply for leave and allows staff to manage leave requests efficiently.

## Features
- User Registration and Login
- Apply for Leave
- View Leave History
- Track Leave Status
- Staff Login
- Approve or Reject Leave Requests
- Automatic Leave Balance Management

## Technologies Used
- Frontend: React.js, CSS, Vite
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- Deployment: Vercel and Render
